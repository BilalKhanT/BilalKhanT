### About
Software engineer working on AI systems, voice agents, and backend applications. Experience in building production applications for enterprise use, including telephony based voice systems, recruitment systems, and mobile applications used in field operations.

---

### Experience

Built voice AI agents using LiveKit for enterprise clients including Meezan Bank, K-Electric, and Bank Alfalah. The system supports Urdu and English calls and handles real-time interaction.

Designed a recruitment system called ATLAS that manages job posting distribution and candidate processing with AI based resume evaluation.

Developed offline first mobile applications for field teams working in utility operations. These applications sync data when internet is available.

Built Android applications using TensorFlow Lite for image classification, object detection, and text extraction from images.

Developed a banking SDK that enables chat and voice based interaction for banking services.

Built KYC systems using machine learning models and NADRA integration for identity verification.

---

### Projects

OculaCare is an eye healthcare system that uses machine learning models to detect multiple eye conditions from images. It also includes a question based flow to collect patient information before diagnosis.
